# PHListing — public site

The public home and privacy policy for the
[PHListing](https://chrome.google.com/webstore) Chrome extension.

| File | Published at |
| --- | --- |
| `index.html` | https://flytorakib.github.io/phlisting-site/ |
| `privacy.html` | https://flytorakib.github.io/phlisting-site/privacy.html |

Both pages are generated from the extension's own repository — `privacy.html`
is built from `privacy-policy.md` by `tools/policy-page.js` there. Edit it at
the source and copy the result here, so the published policy and the one in
the submission package never drift apart.

Issues on this repository are the extension's support channel.
